# bccUFU

Disciplinas com programação no curso de bacharel em Ciência da Computação na Universidade Federal de Uberlândia (UFU).

## Períodos

- **1° Período** — Programação Procedimental
- **2° Período** — Algoritmos e Estrutura de Dados, Programação Lógica, Sistemas Digitais
- **3° Período** — Algoritmos e Estruturas de Dados 2, Arquitetura e Organização de Computadores, Programação Funcional, Programação Orientada à Objetos 1
- **4° Período** — Arquitetura e Organização de Computadores 2, Sistemas de Banco de Dados, Sistemas Operacionais
- **5° Período** — Análise de Algoritmos, Arquitetura e Redes de Computadores, Computação Científica e Otimização, Gerenciamento de Banco de Dados, Modelagem de Software, Programação Orientada à Objetos 2
- **6° Período** — Inteligência Artificial
- **7° Período**:
  - [SD](http://www.portal.facom.ufu.br/system/files/conteudo/gbc074-sistemas-distribuidos.pdf) — Sistemas Distribuídos
  - [IC](http://www.portal.facom.ufu.br/system/files/conteudo/gbc073-inteligencia-computacional.pdf) — Inteligência Computacional
  - [CC](http://www.portal.facom.ufu.br/system/files/conteudo/gbc071-construcao-de-compiladores.pdf) — Construção de Compiladores
  - [PG1](http://www.portal.facom.ufu.br/system/files/conteudo/gbc072-projeto-de-graduacao-1.pdf) — Projeto de Graduação 1
  - [SEG](http://www.portal.facom.ufu.br/system/files/conteudo/gbc235-topicos-especiais-de-seguranca-da-informacao.pdf) — Tópicos Especiais de Segurança da Informação
  - `notebooks` — exercícios extras (ex. Spark)
- **8° Período** — MS, PPI, R2, SEG

## Projetos relacionados

- **FlappyNeuron** — rede neural perceptron multicamadas (multilayer perceptron) treinada para jogar Flappy Bird, feita como trabalho de Inteligência Computacional do 7° Período.
